

## 1. 项目背景 
旨在开发一个轻量级的中文Web应用，帮助用户查询和对比中国主要城市（初期仅限：北京、上海、深圳、广州）的生活成本。数据维度涵盖餐饮、市场购物、交通、居住等核心领域，为异地求职、搬迁或旅行的人群提供数据参考。

## 2. 用户流程
1. **首页/入口**：用户看到一个简洁的搜索框或下拉菜单。
2. **输入**：用户选择目标城市（如：深圳）。
3. **输出**：页面展示该城市的各项生活成本清单，并可显示“预估每月总支出（单人/四口之家）”。

## 3. 核心功能 
### 3.1 城市选择
+ 支持下拉选择：北京、上海、深圳、广州。
+ 默认定位（可选）：根据用户IP自动推荐最近的城市。

## 4. 非功能性需求
### 4.1 数据来源策略
+ **MVP阶段**：由于只覆盖4个城市，建议采用**人工采集录入**的方式。来源参考：
    - 房产中介平台（链家/贝壳）获取租房和房价数据。
    - 外卖平台（美团/饿了么）获取餐饮数据。
    - 生鲜电商（盒马/叮咚买菜）获取市场数据。
    - 招聘网站（Boss直聘/拉勾）获取薪资范围参考。
+ **后期规划**：引入用户UGC（用户提交价格）或爬虫自动更新。

### 4.2 界面体验
+ **网页版**：网页开发和部署流程比较简单
+ **可视化**：使用简单的进度条（如图片中的绿色柱状图）来表示该价格在全国范围内的水平（低 vs 高）。
+ 后续可以开发小程序版本
